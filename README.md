## 🎨 Design & Arquitetura
- **Stack**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, GSAP 3 (ScrollTrigger & @gsap/react), Lenis Smooth Scroll.
- **Navbar Aperfeiçoada**: Logo desacoplada estruturalmente da altura do menu, dobro do tamanho (h-24 a h-28 desktop, h-20 mobile), posicionamento estável e sem afetar botões.
- **Open Graph WhatsApp**: Card otimizado com `og-image_optimized_300.jpeg` (fundo sólido, < 300 KB) e URL canônica dinâmica via `NEXT_PUBLIC_SITE_URL`.
- **Paleta 60-30-10**:
  - 60% Fundo Claro: `#F9F6F0` (Branco Off-White)
  - 30% Estrutura/Títulos: `#7B6253` (Marrom Fundo)
  - 10% Ação/CTAs: `#D4AF37` (Dourado Principal) e `#AA7C11` (Dourado Escuro)
  - Fundo Escuro: `#1A1A1A` (Preto Corporativo)
- **Conformidade CFOAB**: Estrita observância ao Provimento 205/2021 do CFOAB e Código de Ética e Disciplina da OAB.

## 🚀 Como Executar
```bash
# Instalar dependências
npm install

# Executar ambiente de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
